# NEXO

Sistema Visual de Ação e Narrativa.

Projeto pedagógico-tecnológico voltado à mediação visual de ações, relações, temporalidade e construção narrativa.

## Princípio central

**VER → ESCOLHER → AGIR → MUDAR → COMPARAR → SEQUENCIAR → NARRAR**

## Arquitetura inicial

- React
- TypeScript
- Vite
- CSS responsivo
- Sem banco de dados
- Estado apenas em memória na primeira versão

## Execução local

```bash
npm install
npm run dev
```

## Estrutura

- `src/components` - componentes visuais
- `src/data` - vocabulário e regras declarativas
- `src/types` - tipos do domínio
- `docs` - documentação pedagógica e técnica


## Classificação do recurso

O NEXO é apresentado como **recurso digital de Tecnologia Assistiva para mediação visual, comunicação e aprendizagem**.

Foi concebido inicialmente para a comunidade surda e pode apoiar outros contextos em que existam barreiras comunicacionais ou necessidades complexas de comunicação.

O NEXO não é, neste estágio, classificado como um sistema completo de Comunicação Aumentativa e Alternativa (CAA). Seus recursos visuais podem apoiar estratégias de CAA, mas a arquitetura atual é mais ampla e inclui ação, temporalidade, relações, perspectiva, narrativa, mediação pedagógica e registro observacional.

A ferramenta não possui finalidade diagnóstica e não substitui avaliações profissionais quando necessárias.
