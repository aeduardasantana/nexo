# MVP - NEXO

## Objetivo

Entregar a menor versão tecnicamente funcional que permita validar a arquitetura pedagógica.

## Incluído no MVP

1. Biblioteca visual.
2. Personagens, objetos e lugares iniciais.
3. Dez verbos concretos.
4. Cenário.
5. Seleção por clique/toque.
6. Responsividade notebook/mobile.
7. Estados antes/agora/depois.
8. Sequência de cenas.
9. Desfazer.
10. Replay.
11. ERRADO, NÃO SEI e NÃO ENTENDI.
12. Modo livre.
13. Base para modo mediador.
14. VLibras como camada complementar.

## Fora do primeiro incremento

- banco de dados;
- autenticação;
- gamificação;
- avaliação diagnóstica;
- inteligência artificial;
- métricas automáticas de capacidade;
- armazenamento remoto de prontuário.

## Regra-mestra

VER → ESCOLHER → AGIR → MUDAR → COMPARAR → SEQUENCIAR → NARRAR
