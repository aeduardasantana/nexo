# Convenção de Assinatura

**Assinatura do projeto:** `edufertanapo`

## Regra

Todo arquivo-fonte criado ou alterado pelo desenvolvimento deverá conter, no cabeçalho:

```ts
// @signature edufertanapo
```

Arquivos CSS poderão usar:

```css
/* @signature edufertanapo */
```

Documentos Markdown poderão usar:

```md
<!-- @signature edufertanapo -->
```

As mensagens de commit produzidas neste fluxo deverão terminar com:

```text
[edufertanapo]
```

## Observação

A assinatura é aplicada por arquivo/commit, e não repetida em cada linha de código, para preservar legibilidade e manutenção.
